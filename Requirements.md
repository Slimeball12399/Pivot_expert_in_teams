# Requirements
## Functional
1. As a user I would like to see my progress over time so I can see how I have been progressing through using the device
1. As a user I would like to be able to see immediate feedback of how my session is going has been going

1. As a user I would like to be able to book an appoinment with the professional for a practice session

1. As a trainer I would like to see trends of how balance effects speech over time

1. As a trainer I would like to post possible appointemnts so my users can book trainings

1. As a trainer I would like to see live feedback from the training session that I can aslo host for the user

1. As a trainer I would like to see the individual progress of each speaker

1. As a user I would like to create an account and see sessions associated with my acccount

1. As a user I would like to manage my profile including mobile number email, age, etc information that helps inform the trainer

1. As a user I would like to be able to delete my account with all its data to have controll over what I share with the company

1. As a trainer I would like to controll who i train in order to let new users in or let new users know i am fully booked


## Non-functional
1. As a user & trainer I would like to have a resposive side so my user expereience is fluid
1. As a user & trainer I need that the system complies with GDPR
1. As a user & trainer I need to have my data saved even if the connection drops
1. As a user & trainer I need voice and mvoement analysis to be reliable to provide analyis that we can trust
