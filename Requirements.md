# Requirements
## Functional
1. As a user I would like to see my progress over time so I can see how I have been progressing through using the device  
Acceptance criteria:
    - I would like to see an estimation of my current speech score and stability score
    - I would like to see a progression chart of my speech and stability score over time
    - I would like to get explonation on what the carts mean so i can understand teh information I am looking at
    - I would like to see a breakdown of the voice analysis progress on each measure 
    - I would like to see a stability data break down to all of its measures


1. As a user I would like to ensure that sensory data is correct and calibrated so I dont record a bad session.  
Acceptance criteria:
    - I need to be able to see live feedback of the systems assumption of the state
    - I would like to calibrate the device before starting the session if its not correct
    - I need the calibration to be easy to understand and actionable without competencies on the device
    - I do not want the data collected during calibration to be included in any of my progress report
    - I would like to be able to start the calibration from my mobile device  

1. As a user I would like to be able to see immediate feedback of how my session is going and has been going
Acceptance criteria:
    - I would like to see low latency feedback of the boards state
    - I would like to see the analyis data of my short speeches during a session before the sesshion finishes
    - I would like to see live data plotted on a graph of the measueres determining my stability and live text-to-sepeech 

1. As a user I would like to see my past sessions with their associated data
Accaptance criteria:
    - I need to be able to see a list of all my recent sessions
    - I would like to be able to search my past sessions
    - I would like to see all the graphs, plots for each speech and overall session

1. As a user I would like to controll the session I am having in order to accomodate breaks etc and have them separated to sessions
Accaptance criteria:
    - I need to be able to pause, finish, restart my talks, and session
    - I need to be able to start a new talk in the session
    - I would like to be able to exclude a session or talk from the overall analysis


1. As a trainer I would like to see trends of how balance effects speech over time
Accaptance criteria:
    - I would like to see a plot of how sepech and balance relates on all my users
    - I would like to see correlations between the measures of speech and stability with confidence

1. As a trainer I would like to be able to start training sessions that the user can see during the training
Accaptance criteria:
    - I would like to set a new training
    - I would like to specify time user
    - I would like to be able to search in the user list

1. As a trainer I would like to see live feedback from the training session that I can aslo host for the user
Accaptance criteria:
    - I would like to have a live feedback screen
    - I need the screen to adjust to the device i am displaying it on as it might be a TV
    - I would like to see text to speech & stability and avilable voice anaylsis
    - I would like to write comments that i can chose to share to each speech in order to add my professional experience to the analysis

1. As a trainer I would like to see the individual progress of each speaker
Accaptance criteria:
    - I need acces to the individual progres that the users have under their profile
    - I would like to be able to search and and see the users listed with their high level inforamtion to acces the individual progress screens


1. As a user I would like to manage my profile including mobile number email, age, etc information that helps inform the trainer
Accaptance criteria:
    - I need acces to register and log in to the account
    - I need to be able to edit my profile in a scren

1. As a user I would like to be able to delete my account with all its data to have controll over what I share with the company
Accaptance criteria:
    - I would like to anonymize my past sessions
    - I would like to delete all personal data
    - I would like to be able to aslo download all collected data


1. As a trainer I would like to be able to configure the device to connect it to the software I am using
Accaptance criteria:
    - I would like to be able to connect to the device and configure the wifi settings for it

## Non-functional
1. As a user & trainer I would like to have a resposive side so my user expereience is fluid
1. As a user & trainer I need that the system complies with GDPR
1. As a user & trainer I need to have my data saved even if the connection drops
1. As a user & trainer I need voice and mvoement analysis to be reliable to provide analyis that we can trust
