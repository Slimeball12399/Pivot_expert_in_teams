{% comment %} Confirm dialog: "Are you sure?" before something that can't simply be undone, in the style of the other dialogs (icon tile, title, text, Cancel and a red button). One per page; confirm-dialog.js opens it from any button that has data-confirm-url, and sends that request when confirmed: {% include "web/components/confirm_dialog.html" %} data-confirm-url where the request goes (required) data-confirm-method "DELETE" (default), "POST", "PATCH", ... data-confirm-title the question data-confirm-body what happens, in one plain sentence data-confirm-label the red button's text (default "Delete") On success (a 2xx answer) the page reloads, so a toast the view left shows; an error ({"errors": {"__all__": [...]}} or any other failure) shows in the dialog, which stays open. The page loads web/css/dialog.css and web/js/confirm-dialog.js. {% endcomment %}
